SUPERNOVA GAME

Autora: Agustina Espinoza Curso: Taller de Diseño de Interfaces

Descripción del proyecto

Supernova Game es un videojuego espacial interactivo desarrollado en Processing y controlado mediante Arduino Uno.

El jugador controla una nave espacial utilizando un potenciómetro deslizante y dispara proyectiles mediante un botón físico.

Funcionamiento

Slider: mueve la nave de izquierda a derecha.
Botón: permite disparar y reiniciar el juego.
Estrellas recolectadas: +10 puntos.
Meteoritos destruidos: +25 puntos.
Colisión con meteorito: GAME OVER.
Materiales y programas

Arduino Uno
Processing
Potenciómetro deslizante
Botón pulsador
MDF cortado con láser
Comunicación serial USB
Archivos del proyecto

ejercicio_final_slider: código del videojuego en Processing.

Cómo ejecutar

Conectar Arduino Uno al computador.
Cargar el código de Arduino.
Abrir el proyecto en Processing.
Seleccionar el puerto serial correcto.
Ejecutar el juego.
